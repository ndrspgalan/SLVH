## Description

This repository contains the official public version of the doctoral thesis "Human Vitality Liberation System (SLVH)".

SLVH proposes an integrative theoretical framework for human vitality, formalized through the functional relationship:

> V = P − O

where:

- V = Vitality
- P = System Power
- O = Systemic Obstruction

The repository is intended for academic reading, scientific discussion, citation, and archival purposes.
